# foodcoma

a cooking game made with PyGame with hardware made by Selena and Assets made by Almo!

As the theme is "in your dreams" we all thought about food so we love food! So for our project we made a cooking game where you have to feed Pancake as fast as possible to put them in a food coma!

You control the game with our custom gamepad made out of cardboard consisting of an UNO R3, 3x buttons, a distance sensor, and a joystick! There's 3 stages, you mix your batter, flip you pancakes, and stack them with toppings!
